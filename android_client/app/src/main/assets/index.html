🛠️ Can't connect to Laptop #2? Tap for Help ▼
1. Is the server running on Laptop #2?
Make sure you double-clicked start_server.bat on Laptop #2 and left the black terminal window open.
2. Windows Firewall Blocking Port 5000 (Most Common!)
Windows Firewall on Laptop #2 often blocks incoming connections by default. On Laptop #2, right-click allow_firewall.bat and select Run as administrator to unblock port 5000 in 1 second!
3. Wi-Fi Profile: Set to 'Private' (Not 'Public')
Windows blocks all local network sharing if your Wi-Fi is marked as "Public Network". On Laptop #2: Open Windows Settings > Network & internet > Wi-Fi > tap your network name > change to Private network.
4. Verify Exact IP Address on Laptop #2
Each laptop has a different IP. On Laptop #2, open Command Prompt, type ipconfig, and look for your IPv4 Address (e.g. 192.168.1.XX).
